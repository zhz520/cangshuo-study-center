# Web 全站 UI/UX 重构方案

日期：2026-11-07。范围：官网、认证页、学习端、答题页、管理后台和异常页。目标是在不删功能、不改后端接口和数据结构的前提下，统一信息架构、布局和视觉语言。

## 一、先解决的结构问题

当前 Web 有三套内容宽度：学习端 1160、普通页 1080、后台 1280；页头有 AdminPageHeading 和手写标题两套；表格、筛选、弹窗和空状态仍有页面各自实现。继续逐页改颜色会反复出现“这边改了、那边还是旧的”。

重构顺序固定为：设计令牌 → 基础组件 → 三套布局壳 → 页面模板 → 全量替换 → 路由回归。先统一骨架，再改页面。

## 二、视觉方向

- 中性灰白底，深色文字，深色主操作按钮。
- 品牌蓝只用于当前选中、进度、链接和少量状态，不做大面积按钮和背景。
- 圆角 10–14px，边框 1px，阴影只保留极轻的一层。
- 不使用渐变、玻璃拟态、发光、彩色图标墙、巨型会员广告。
- 列表和目录优先于卡片；卡片只用于需要建立边界或聚合的数据块。
- 中文字体优先系统字体和思源黑体；正文 13–15px，辅助 10–12px，页面标题 22–24px。

## 三、页面族群与布局模板

| 族群 | 布局模板 | 页面 |
| --- | --- | --- |
| 官网 | 1120–1200px 营销页，两段式 Hero + 紧凑功能区 | `/` |
| 认证 | 左右分栏，左侧品牌叙事、右侧单列表单 | `/login`、`/register` |
| 学习工作台 | 1160px 顶栏，主栏 + 侧栏，移动端底部导航 | `/home`、`/analysis`、`/stats`、`/data` |
| 沉浸答题 | 无学习端导航，题干最大 760px，底部固定操作栏 | `/exam/:subjectId` |
| 内容与工具 | 820–960px 阅读宽度，顶部返回和单一主操作 | `/article/:id`、`/download`、`/score-query`、`/export` |
| 协议 | 760px 阅读页，目录锚点 + 正文 | `/agreement`、`/privacy` |
| 后台数据 | 232px 侧栏 + 1280px 工作区，页头 + 工具栏 + 表格 + 分页 | 用户、题库、卡密、报错、评论、考试、课程表、文章、导出授权 |

## 四、统一组件

1. `PageHeader`：eyebrow、标题、说明、右侧操作。所有页面共用一套字号和间距；后台不再手写标题。
2. `Toolbar`：搜索、筛选、批量操作、结果计数。窄屏时筛选进入底部抽屉。
3. `DataTable`：统一表头、52px 行高、常驻行操作、空状态、分页；移动端自动转为紧凑行列表。
4. `FormSection` / `SettingRow`：标签、说明、控件、保存状态统一；不再用大卡片包单行设置。
5. `ModalShell` / `ConfirmDialog`：统一遮罩、头部、可滚动主体、底部按钮；宽弹窗 880px，普通 520px。
6. `EmptyState` / `LoadingState` / `ErrorState`：所有页面共用，不再出现英文 LOADING 和彩色大 spinner。
7. `MetricStrip` / `ChartPanel`：指标条和图表容器统一；图表只用一个强调色和中性坐标轴。
8. `PageShell`：公开页、学习端、后台、沉浸页四种宽度和导航规则。

## 五、交互规范

- 页面切换 120–180ms 淡入，不做复杂位移。
- 加载使用骨架或轻量状态行，超过 300ms 才显示加载提示。
- 列表筛选状态写入 URL，返回页面不丢失搜索和筛选。
- 表格操作始终可见，不依赖 hover；批量操作固定在底部并显示已选数量。
- 表单保存有成功、失败和保存中状态；未保存离开时提示。
- 答题页保存进度、答题卡分页、收藏、纠错、解析开关和交卷前检查全部保留。
- 深色模式使用同一套 token，图表、图片边框、输入框和禁用态一起适配。
- 触控目标至少 44px；桌面控件 32–40px。

## 六、实施阶段

### 阶段 1：设计系统和三套壳

- 清理 `theme.css` 与 `study-ui.css` 重复变量。
- 新增 `PageHeader`、`Toolbar`、`DataTable`、`ModalShell`、`EmptyState` 等基础组件。
- 统一 `AppLayout`、`AdminLayout`、`AuthLayout` 和官网容器宽度。
- 先不碰页面 script 的业务逻辑。

### 阶段 2：五个核心页打样

- 官网 `/`
- 学习首页 `/home`
- 答题页 `/exam/:subjectId`
- 后台仪表盘 `/admin`
- 用户管理 `/admin/users`

这五页覆盖营销、工作台、沉浸答题、数据视图和 CRUD 列表。确认骨架后，其他页面只做同模板替换。

### 阶段 3：学习端其余页面

- `/analysis`、`/stats`、`/data`、`/export`
- `/download`、`/score-query`、`/article/:id`
- `/login`、`/register`、协议页、404

### 阶段 4：后台全量

- 题库管理、知识结构、考试系统、题目报错、访问控制、导出授权
- 资源文章、评论、卡密、课程表
- App 版本、系统设置、第三方服务

### 阶段 5：全量验收与发布

- 24 个路由逐一检查：页面可打开、数据可加载、空状态可显示、错误可重试。
- 功能矩阵逐项对照：搜索、筛选、分页、批量、导入、导出、发布、审核、保存、删除、权限和会员状态。
- 视口：390、768、1024、1440。检查横向滚动、遮挡、触控和长文本。
- 浅色/深色各巡检一次。
- 构建、Web 测试、服务端测试。
- Web 分批发布，保留完整备份；不改 API、数据库和 App 版本号。

## 七、功能保护

- 页面改造以模板和样式为主，保留所有 `v-model`、事件、API 调用、分页参数和权限判断。
- 不删除任何后端接口，不改变题库格式、会员判断和题目访问控制。
- 导入、导出、批量审核、发布状态、课程表编辑、系统设置等操作逐页回归。
- 每阶段完成后先本地构建和截图，再进入下一阶段。

## 八、验收标准

- 同一类页面使用同一页头、工具栏、表格和空状态。
- 一个功能只有一个主入口，不出现重复按钮。
- 主操作颜色一致，页面不出现蓝黑混用。
- 页面之间无宽度跳变，后台所有页面内容区对齐。
- 390px 下无横向滚动，表格转为行列表。
- 深色模式无白块、无色值突变。
- 所有原有功能仍可用。
