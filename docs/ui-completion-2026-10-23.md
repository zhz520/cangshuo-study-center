# 页面统一与学习功能修复

日期：2026-10-23。范围：Android、Web、管理后台、学习统计接口。

## 本轮改动

- Android 工具页统一 56dp 页头、标题排版、分割线和返回控件；补齐进制、BMI、计算器、日期、QQ 绑定、投稿和内嵌网页。计算器与秒表采用紧凑操作区，图片和文档工具保留必要预览区域。
- Web 后台用户、题库、访问控制、结构、考试、报错、文章、评论、卡密、课表、应用版本和系统设置接入公共页面样式。题目管理改用连续分隔列表，编辑和删除操作常驻；导入导出与筛选功能保留。
- App 与 Web 答题卡每页 50 题，下一页按需读取后续批次，已加载的历史页可回看。App 从中间断点恢复后能向前加载；免费范围仍由 API 限制为每科前 20 题。
- App 首页和统计页都有排行榜入口。三种排行支持科目筛选、50 条分页、刷新和个人主页；从个人主页返回保留已加载排名。切换科目清除旧科目行，避免数据错配。
- 学习统计排除已删除学习记录和停用题目。日期使用 `YYYY-MM-DD`，避免 MySQL DATE 转 UTC 后前移一天；App 本机记录同样使用 Asia/Shanghai 日期。
- API 新增兼容字段 `detailed-stats.today`，含 day / total / correct / accuracy。App 首页显示今日完成、今日正确率、本机前台学习时长和连续天数；无作答时正确率显示破折号。重复提交相同答案明确刷新 `updated_at`。
- Plus 个性化从「我的」和会员页进入，读取并保存前核验真实账号会员；支持问候、每日一句、5–200 题目标、反馈模式、16/18/20/22sp 题干字号。当前账号本机保存，进入练习读取，系统动态字号继续生效。

## 数据统计边界

今日题数统计普通题库当天最后提交的不同题目；同一道题当天重复提交只计一题。现有 `user_progress` 每人每题只有一行，无法恢复完整答题事件历史。错题练习为保留历史错误而不覆盖服务端原作答；模拟考试有独立记录，二者不混入首页题库提交计数。时长为本机前台练习，非跨设备同步时长。

连续学习允许今天尚未开始时延续截至昨天的连续天数。失败刷新保留最近成功内容，跨日过期的今日指标不继续冒充当天数据。
