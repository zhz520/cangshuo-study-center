# UI 连贯性与 Plus 身份展示

日期：2026-10-24。范围：Android App、Web 学习端、管理后台。

## Android

- 首页公告从仅在通知弹窗中读取，改为首页可见的紧凑公告条；公告关闭时不显示，接口失败时区分“加载失败”和“暂无公告”，并保留上次成功内容。
- “我的”页的主题模式与重点色不再先进入“更多设置”。两处共用 `AppearanceSheet`，选择后立即生效；“更多设置”复用同一组件。
- “更多设置”的普通条目改用与“我的”一致的线性图标，设置分组采用统一标题层级。
- Plus 个性化增加头像装饰和会员铭牌预览。头像装饰、铭牌开关由服务器保存；会员过期后，服务端自动返回普通头像状态。
- 排名榜与个人主页展示同一套 Plus 头像和铭牌。会员标识使用低饱和金属色、细边框和小尺寸铭牌，不使用大面积渐变或动画。
- “我的”页的会员入口改为紧凑状态行，保留账号权益入口，并避免黑色巨幅会员广告占用首屏。

## 服务端

- 新增 `GET /api/data/appearance` 和 `PUT /api/data/appearance`。保存前重新读取当前账号会员状态，客户端提交的 `is_plus` 或会员到期时间不会被信任。
- `avatar_frame` 只接受 `none / obsidian / champagne / azure` 白名单；`badge_visible` 必须是布尔值。
- 新增 `user_appearance` 表，按用户保存装扮。排行榜和个人主页通过服务端补充 `appearance`，到期账号自动降级。
- 装扮读取失败时排行榜仍返回，装扮显示为普通样式，避免个性化数据影响主要学习功能。
- `home-data` 明确使用 `no-store`，确保公告更新后 App 能及时读取。

## Web 学习端

- `#subjects` 题库目录改为“专业索引 + 科目面板”的紧凑目录，保留搜索、最近选择、加载、空状态和科目题量。桌面为双栏，移动端自然堆叠。
- 移除整屏重复的单字色块和同文案行；索引使用编号、标题和次要说明，选中项使用轻量底色与左侧指示线。
- 修正锚点定位，使页面跳转到题库时不会被吸顶导航遮住。
- 答题页右上角操作改为可访问的“练习与工具”菜单，统一线性图标和两行说明。智能练习可在当前页进入或退出，不再要求整页刷新。
- 菜单支持 `Esc` 关闭、点击遮罩关闭和 `aria-expanded`；桌面为浮层，窄屏为顶栏下方可滚动面板。顶部进度按总题数计算。

## 管理后台

- 全部模块继续使用统一的 `AdminPageHeading`、表格、输入框和操作按钮规范，并补充统一的分区标签、指标条、目录列表、空状态和行操作。
- 系统设置改用下划线分区标签；快捷链接从彩色卡片网格改为紧凑目录列表，编辑和删除操作常驻可见。
- 题库结构改为专业索引列表和科目网格，移除渐变字母块、模糊装饰和空状态插画。
- 文章模块将四个统计卡片合并为一条指标栏；文章占位、置顶标记和空状态采用中性排版。
- 题目、考试、评论、卡密、课表等模块移除装饰性 emoji 操作，统一为文字线性操作；原筛选、导入导出、发布、审核和删除功能保留。
- 导出授权与第三方服务补齐公共页头、工作台宽度、表格与表单间距；导出搜索和分页按钮在窄屏保持 44dp 触控高度。

## 题库访问控制重构

- 页面改为“账号目录 + 单账号权限面板”，不再使用 25 列横向表格。列表显示账号身份、访问模式和分类数量，搜索支持用户名、昵称和 UID。
- 明确区分“全部专业”和“指定分类”。原来的“全部撤销”会清空权限记录，而服务端把零记录解释为全部开放，实际会产生相反结果；该操作已移除。指定分类模式至少保留一个专业，否则禁止保存。
- 每次保存只作用于当前账号，并在保存前显示范围确认；未保存修改在切换账号或关闭面板时会提示放弃。
- 服务端批量接口增加用户与专业存在性校验、重复专业去重和数据库事务；任何一步失败都会回滚，不再出现删旧权限后写入失败的空档。
- 生产验证：管理员列表返回 200，共 396 条权限记录；匿名访问 401；无权限账号的空列表保存返回 200 且记录数不变；不存在用户返回 404。用户 53、学习记录 46,639、收藏 680、考试记录 73、有效题目 133,444 均未变化。
