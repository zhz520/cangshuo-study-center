# 2026-10-22 生产更新与验收

本次更新完成了全量题库格式统一、AES-256-GCM 存储加密、API 权限修复、Web 前端更新和 Android 页面衔接修复。正式数据在切换前后保持同一批题目 ID，账号、进度、收藏、考试记录与成绩未重建。

## 当前生产状态

- 普通题库 133,444 道、试卷题目 834 道，全部保存为 AES-256-GCM 密文；`answer`、`analysis` 为空的明文列，`options` 不保存明文选项。
- 搜索使用独立派生密钥的盲索引，共 16,995,888 个 token；服务端解密候选后再校验连续文本。
- 免费用户每科只能读取前 20 道有效题；Plus 用户按 50 题分页。直接改题目 ID、搜索、推荐、收藏练习和错题入口共用服务端权限边界。
- 上传接口要求登录并检查真实图片文件头；视频链接解析限制到受支持平台、HTTPS 和公网地址，重定向重新校验，避免把服务器当作内网代理。
- 生产 API 仅监听 `127.0.0.1:9898`，Nginx 提供 HTTPS；未认证的题库、管理、上传和机器人接口返回 401。 防火墙已移除 9898 公网放行；实际从公网连接 9898/9899/3306/6379 均超时，只有 Nginx 的 80/443 提供业务访问。

## 格式统一与加密

全量格式扫描覆盖启用和停用题目。统一结构为：题干和解析保留原富文本；普通选项为 JSON 对象；判断题固定 A 正确、B 错误；排序题保留有序数组；单选、判断为字符串答案；多选为去重排序的逗号分隔标签；填空保留文字答案。

转换在独立副本逐条验证幂等性、判分含义和明文往返，再通过事务写回。共 69,128 条记录发生格式转换，题目 ID、科目、原始编号、标签、分类和启停状态差异为 0。

加密在另一组独立副本完成，耗时约 1,180 秒。全量解密后 133,444 道普通题和 834 道试卷题的明文指纹与统一格式结果完全一致，然后才切换到正式表。

仍有 284 道原有内容质量问题，主要是缺失选项、答案指向不存在选项、重复答案或空题干。这些记录保留并登记在 [question-format-migration.md](question-format-migration.md)；没有用推测内容替换原题。

## App 与页面衔接

- 主栏目切换使用 140ms 淡入淡出，详情页进入和返回使用 220ms 短距离方向滑动。
- 统一页面加载反馈：延迟 180ms 后显示，避免缓存请求闪屏；已有内容刷新时保留原列表。
- 从会员页返回练习会保留当前题目、草稿和计时，并补齐当前 50 题批次，避免升级后跳过第 21–50 题。
- 收藏、资源和错题在返回时只更新状态，不重置已加载列表和筛选。
- Access Token 刷新按旧会话匹配，网络超时或服务端 5xx 不再直接清除登录；明确失效时才返回登录页。
- 历史考试记录保留题号、作答、得分和明细；参考答案与解析从受保护试卷表按本人记录读取。

## 部署中发现并修复的问题

1. 免费预览的依赖子查询在 133k 题目上超过 10 秒。改为按科目排名的窗口查询，免费 20 题请求从超时降至约 0.6 秒。
2. 生产 Nginx 未把 `X-Forwarded-Proto` 传给 Node，HTTPS 请求被误判为 426。已在 Nginx 代理块补齐并重载。
3. 首次发布遗漏新数据库解密适配器，接口曾短暂返回密文。补齐 `config/db.js` 后重启，密文泄露状态未写入用户数据；随后正式回归全部通过。
4. Web 根目录的 `.user.ini` 是受保护系统文件，部署脚本改为跳过该文件，其他前端资源正常更新。
