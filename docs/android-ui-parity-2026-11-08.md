# Android 截图参考版对齐

日期：2026-11-08。

本轮按用户提供的移动端界面合集，对原生 Android 页面做对齐，不修改服务端接口、题库数据、会员判断或计分规则，也不调整版本号。

## 页面结构

- 主导航保持：首页 / 题库 / 资源 / 统计 / 我的。
- 首页：问候、继续刷题、今日进度、四个常用入口、每日一句卡片、考试倒计时。
- 题库：标题栏搜索与刷新、科目搜索、常用 / 热门 / 最近 / 未开始筛选、专业栏、科目列表。
- 错题本：错题总量、待复习与已掌握、黑色开始复习按钮、按科目分组；科目详情增加收录顺序 / 掌握程度切换。
- 刷题：居中试卷标题、题号与细进度、计时、收藏、紧凑选项、固定底栏。
- 答题卡：接近全屏的底部弹层，按题型分组，显示题号区间，保留每页 50 题分页。
- 结果：分数环、轻量彩点、正确 / 错误 / 未做、用时 / 题量 / 正确率、查看解析与错题重练。
- 我的：真实头像与 Plus 标识、黑色会员条、账号与安全、更多设置；其余功能分组进入设置。

Plus 标识统一为金色细环加号：黑色会员条、昵称旁小标识和头像角标使用同一套加号图形，不再使用皇冠或四角星。

## 交互与去重

- 结果页“查看解析”回到本次练习，保留已提交答案；返回键与顶栏返回结束本次练习回到首页。
- 学习排行从首页和错题菜单移到统计页，统计仍是唯一主导航入口。
- 错题菜单只保留收藏、数据中心和返回，学习统计与排行不再重复出现。
- “我的”只保留头像、会员条、账号与安全、更多设置。外观、意见反馈、评分、分享、联考成绩查询、后台管理、应用更新、版本记录、缓存、关于和法律信息统一收进“更多设置”。
- 资源中心移除重复刷新按钮，保留搜索、分类、精选、文章、工具、常用网站和投稿。
