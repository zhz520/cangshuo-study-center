## 四个核心流程

### 首页

继续学习读取上次科目和题目位置；无历史时引导选择科目。今日完成数来自现有 `detailed-stats.weekHeatmap`，目标可选 10/20/30/50/100 题。连续学习来自真实统计，加载失败显示缺省符号及重试，不伪造完成量。每日一句展示中英文内容，公告收进通知入口，考试倒计时可进入模拟考试。

### 题库

使用 `getMajors()`、`getSubjects(null)`、`getProgress()` 构成完整的可访问科目目录。搜索支持科目和专业名称，搜索时跨分类匹配；顶部保留原有全局题目搜索入口。左侧专业与常用/最近学习/未开始筛选可组合，导航记录按账号本机保存；行内显示题量及已有进度。

### 刷题

阅读区域与固定底栏分离；顶部保留返回和更多菜单，收藏移至题号、进度和计时所在行。选项用字母、勾/叉、说明及颜色共同表达状态，避免只靠颜色判断。

- 默认延续单选/判断即时反馈；可切换为提交后反馈。多选/填空明确提交后展示答案与解析。
- 收藏请求有加载/进行中状态，避免连点产生竞争，失败恢复该题状态并提示错误。
- 保存答案期间暂时禁止跳题与退出，失败保留选择以便重试。
- 用户未提交的作答草稿本机保存；已提交的服务端记录优先，不用草稿覆盖成绩。
- 恢复学习按上次所在批次请求 50 题，支持向前补批次、向后加载。不会为恢复位置在启动时循环下载整个题库。
- 答题卡区分当前、已提交、未提交与用户标记，可快速跳题；结束前明确显示本次已加载/已答/未答数量。
- 结果仅统计本次已加载的题目，弹窗明确说明，避免将局部结果当成全科成绩。
- 收藏、纠错反馈、随机练习、AI 解析、图片与公式仍可用；切题会取消旧题 AI 流，避免解析串题。
- 嵌入式富文本接入本地 DOMPurify；避免直接将原始题目 HTML 插入页面。公式字体响应系统字号，WebView 不再反复无条件重载；题内 HTTPS 链接由外部浏览器打开。

### 错题本

概览按科目展示总数/待复习/已掌握，并进入科目详情。详情提供已加载题目的题型、分类（有数据时）、掌握状态和关键词筛选；紧凑列表支持单题复习、每批最多 20 题的选中复习与批量掌握标记。

错题复习继续保留首次作答成绩，不调用首次成绩写入来冒充复习结果。掌握状态明确标注为本机保存。复习队列逐题经过原有授权接口读取，仍受服务端访问控制和预算约束。

## 已扩展的其他流程

### 收藏与搜索

收藏采用科目分组列表，支持已加载内容的关键词、科目和题型组合筛选，最多 20 题的选中练习、当前列表练习和批量取消收藏。数据使用原有收藏题目接口，按 50 题分页，不为筛选预先抓取全部题干。

取消收藏后重新对齐第一页，避免删除导致 offset 分页漏题；部分失败关闭操作弹窗并保留可重试提示。加载与删除互斥，失败重试刷新当前列表。全局题目搜索保留服务端权限校验和手动分页，旧请求不会覆盖新筛选结果。

### 资源、阅读和工具

资源中心改为搜索、分类、轻量精选与紧凑文章列表；工具、常用网站和投稿有明确入口。分类切换取消旧请求，清除上一分类内容；分页和错误重试均保留。

文章阅读页以标题、作者、摘要、正文、讨论组织信息，保留分享、字号、作者主页和评论。评论提交失败保留草稿，避免重复发送；删除和发布继续走原接口及邮箱绑定规则。正文和投稿预览共用本地安全富文本组件，外链只接受用户主动点击的 HTTPS 链接。

工具目录保留列表/双列、搜索、分组、排序及常用工具；课程表改为按日查看。各工具内部的专用输入、计算及网络功能保留，继承全局主题和基础控件；没有为外部网站、后台管理或每个独立工具声称单独完成交互重写。

### 学习统计

累计作答、整体正确率、连续学习、每日作答量、科目与题型表现继续使用真实统计接口。错题掌握数来自本机标记，AI 学习建议保留原有接口并防止重复请求。

新增近 7 天本机学习时长和正确率趋势：只累计前台可阅读的练习/考试时间，每 10 秒及离开时保存；正确率按本机当日首次作答记录，重复作答不覆盖当天首次结果。考试记录使用服务端返回的明细。这些数据不回填历史、不参与排名、不冒充全账号跨设备时长；图表提供文字和无障碍描述。

### 模拟考试、答题卡和结果

考试流程重新组织为目录/记录 → 须知 → 沉浸作答 → 检查交卷 → 结果明细。试卷题量、时限、及格线和可参加状态来自接口。原有切换应用、锁屏或退出即中止记 0 分的业务规则明确展示并保留。

- 截止时间由 ViewModel 持有并使用单调时钟，页面重组/旋转不重新计时。
- 单选、多选、判断、填空复用统一题目组件；考试时不提前展示标准答案。
- 答题卡区分当前、已答、未答和标记，支持跳题、跳到未答及交卷前检查。
- 时间结束锁定答案并尝试交卷；提交失败保留会话和手动重试入口。
- 中止结果在接口确认后更新；同步失败显示明确重试，不伪造提交成功。
- 历史结果按记录编号匹配，成绩与明细以服务端为准，不串用上一场结果。
- 普通练习结果采用轻量指标，正确率按答对题数/已答题数计算，并说明本次已加载范围。

### 我的、会员、设置与辅助页面

个人入口、公开主页、账号设置和会员改为紧凑资料与分组列表。会员状态清楚可见，保留黑色会员条，取消装饰性光效。原有主题/重点色、反馈、评分、分享、更新、版本记录、缓存、许可、隐私和退出登录流程保留。

会员激活仅更新会员字段；刷新会员从完整资料更新账号，避免以缺省 User 覆盖邮箱或 QQ 绑定信息。原有服务端会员判断、QQ 绑定证明和登录校验保持有效。

登录/注册表单统一间距、字号和最小操作尺寸，支持滚动及软键盘。排行采用列表，学习数据中心按导出、导入、重置分组；旧格式导入明确选择科目，重置同步清理本机练习断点。真实业务数据仍通过原接口处理。

## 数据限制与适用范围

当前接口没有可靠的章节树、累计错误次数、复习掌握同步或跨设备学习时长明细。此轮不为这些字段编造数据，不把 `category` 冒称章节，不将“收录顺序倒序”冒称最近答错时间。错题搜索/筛选明确作用于已加载内容，用户可继续加载下一批；没有在后台批量抓取全部题干。

本机数据按账号隔离，包含科目导航元信息、目标、掌握标记、断点、用户作答草稿和最近 30 天的时长/首次作答正确与否；不持久化题干、选项、标准答案或解析。掌握标记与本机趋势尚不跨设备同步。

主要学习与账号页面已扩展统一。未来章节树、错误频次和跨设备复习需要明确服务端字段后再接入；未以推测字段替代真实业务数据。
